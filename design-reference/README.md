# EPEDE design reference

This folder is the visual source of truth for the EPEDE redesign.

- `EPEDE Homepage.html` — open in a browser to see the target design (works offline).
- `EPEDE Master.dc.html` — readable source of the same design (layout, colours, fonts, motion).
- `assets/hero/` — stand-in photos (Wikimedia Commons). Replace with EPEDE's own photography.
- `procode-spec.md` — add the ProCode implementation prompt here.

Rule: copy the look, never the content. Keep every existing page's text, data, formulas, routes and tools.
